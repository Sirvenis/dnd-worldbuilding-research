# D&D World-Building Research

A comprehensive research compendium for Dungeons & Dragons world-building, campaign design, and dungeon mastery. Reusable across multiple campaigns and world-building projects.

## Purpose

This repository collects research on D&D rules, mechanics, published settings, world-building craft, and DM best practices. It is intentionally separate from any specific campaign or world project so the research can inform multiple campaigns.

## Structure

```
research/
  01_DnD_Research_Compendium.md    — Core rules, editions, ownership, cosmology, DragonLance deep dive
  02_2024_DMG_Worldbuilding.md     — Revised DMG world-building tools, encounter design, bastions
  03_Faction_Design.md             — How published campaigns structure rival factions
  04_Session_Zero.md               — Best practices for Session Zero
  05_Campaign_Pacing.md            — Structuring long campaigns into acts/arcs
  06_Map_Making_Tools.md           — Digital and physical map-making resources
```
